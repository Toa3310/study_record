# 学習記録アプリ（Web版）

## 概要

日々の学習内容と学習時間を記録・管理するためのWebアプリケーションです。
ブラウザ上から学習記録の保存・一覧表示・平均学習時間の確認ができます。

---

## 作成背景

日々の学習を記録し、継続状況や学習量を可視化したいと考え、本アプリを作成しました。
また、**実用的なツールを自分で設計し、Webアプリとして実装する経験を積むこと**を目的としています。

---

## 使用技術

* Python
* Flask
* CSV（データ保存）
* HTML / CSS

---

## 主な機能

### ① 学習記録の保存

* 日付・学習内容・学習時間・コメントを入力
* CSVファイルにデータを保存

---

### ② 記録の一覧表示

* 保存されたデータをカード形式で表示
* コメント未入力時は「なし」と表示

---

### ③ 平均学習時間の算出

* 記録された学習時間の平均を計算・表示
* 不正なデータが含まれていても例外処理で対応

---

### ④ 並び替え

* 記録を日付順（古い順）で表示

---

## 工夫した点

* Flaskを用いたルーティング設計（`/`, `/record`, `/records`）
* テンプレート継承（base.html）によるレイアウト共通化
* CSVを用いたシンプルなデータ管理
* 例外処理による入力ミス・不正データへの対応
* カード形式のUIによる視認性の向上

---

## 画面構成

* `/`：トップページ（アプリ概要・各機能への導線）
* `/record`：学習記録の入力ページ
* `/records`：記録一覧・平均表示ページ

---

## 実行方法

```bash
python app.py
```

ブラウザで以下にアクセス：

```
http://127.0.0.1:5000
```

## 現在の課題

* データ保存がCSVのため、検索や高度な集計が難しい
* ユーザーごとの管理ができない
* UIは最低限のため、操作性の改善余地あり

# 学習記録アプリ

## 概要

日々の学習内容と学習時間を記録・管理するためのアプリケーションです。
CLI（コマンドライン）上で動作し、学習記録の保存・一覧表示・平均学習時間の確認ができます。

---

## 作成背景

日々の学習を記録することで、継続状況を可視化したいと考え、本アプリを作成しました。
また、単にプログラムを書くのではなく、**実用性のあるツールを自分で設計・実装する経験**を積むことを目的としています。

---

## 使用技術

* Python
* CSV（データ保存）
* 標準ライブラリ（csvモジュール）

---

## 主な機能

### ① 学習記録の保存

* 日付・学習内容・学習時間・コメントを入力
* CSVファイルにデータを保存

### ② 記録の一覧表示

* 保存されたデータを一覧形式で表示
* コメントが未入力の場合は「なし」と表示

### ③ 平均学習時間の算出

* 記録された学習時間の平均を計算・表示
* 不正なデータがあった場合も例外処理で対応

### ④ エラーハンドリング

* 数値入力ミス（ValueError）への対応
* 不正入力時のメッセージ表示
* モード選択ミス時のランダムメッセージ表示

---

## 工夫した点

* 機能ごとに関数を分割（記録処理・平均計算）
* CSVを用いたシンプルなデータ管理
* 例外処理を用いて、入力ミスや不正データに対応
* CLI上での使いやすさを意識したメッセージ設計
* ランダムメッセージによる軽いUX向上

---

## 実行方法

```bash
python study_record.py
```

実行後、以下のモードを選択できます：

* 1：学習記録の追加
* 2：記録の一覧表示
* 3：平均学習時間の確認

---

## 現在の課題

* データの保存形式がCSVのため、検索や集計の柔軟性に限界がある
* UIがCLIのため、直感的な操作が難しい

---

## 今後の展望

### Webアプリ化（Flask）

本アプリをWebアプリケーションとして拡張し、以下の機能を実装予定です。

* フォームからの学習記録入力
* カレンダー形式での日付選択
* 記録の一覧表示（ブラウザ上）
* 平均学習時間の表示

---

### 機能拡張

* 月ごとの平均学習時間の算出
* グラフによる可視化
* データベース（SQLiteなど）への移行
